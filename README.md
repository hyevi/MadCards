**Встречи в реальном мире.** Телефон сам замечает других людей с MadCards рядом по Bluetooth, обменивается карточками и записывает, где и когда вы встретились.

> Open Source · GPL-3.0 · без аккаунтов, без сервера, без слежки

![Превью](Image/app-preview.png)

## ✨ Что умеет

| | Функция | Описание |
|---|---|---|
| 🪪 | **Карточка** | Имя, ID и аватар. Всё, что вы показываете другим, — это карточка |
| 🧑‍🎨 | **Аватар** | Цвет волос, причёска (4 варианта), аксессуар (очки, кепка, наушники), цвет одежды |
| 📡 | **StreetPass по BLE** | Фоновая служба рассылает карточку и ищет других с приложением рядом |
| 🤝 | **Обмен карточкой** | Телефоны подключаются по Bluetooth LE и читают карточку друг друга |
| 📍 | **Место встречи** | Записывает, где вы были в момент встречи, с названием улицы или района |
| 🕒 | **История** | Список последних встреч с аватаром, местом и временем. Открывается на карте |
| 🎨 | **4 темы** | Тёмная, светлая, киберпанк и «Нинтендо» |
| 🔒 | **Приватность** | Всё хранится на телефоне. Очистить историю или удалить всё можно в один тап |

## 🧭 Как это работает

```
 Телефон A                                   Телефон B
 ─────────                                   ─────────
 рассылает BLE-рекламу (UUID сервиса)  ───▶  видит рекламу, подключается
                                             читает карточку A (JSON, ~200 байт)
 видит B, подключается           ◀───        читает карточку B
 читает карточку B                           записывает встречу + место
 записывает встречу + место                  
```

1. Обе стороны одновременно рассылают BLE-рекламу и ищут друг друга.
2. Найдя устройство MadCards, телефон подключается по GATT и читает карточку.
3. Встреча записывается на **каждом** телефоне со **своим** местом. Координаты собеседника не передаются.

### Правила встреч

- ⏳ **Один человек — раз в 6 часов.** Повторные встречи в этом окне не засчитываются.
- 🔢 **Не больше 10 встреч в сутки.** Защита от «фарма» и случайных всплесков.
- 📍 **Место:** свежее определение (до 8 секунд), иначе последнее известное не старше 10 минут, иначе встреча без места.

## 📲 Требования

- Android **8.0+** (API 26), рекомендуется Android 12 и выше
- Телефон с **Bluetooth LE** (без него приложение не установится)
- Разрешения: Bluetooth, геолокация, уведомления
- Для встреч с собеседником у обоих должно быть приложение и включённый StreetPass

## 🚀 Установка и сборка

### Вариант 1. Готовый APK

Скачайте `madcards-debug-apk` из GitHub Actions (вкладка **Actions → Build MadCards APK**) и установите на телефон. Разрешите установку из неизвестных источников.

### Вариант 2. Собрать самому

Исходники лежат в `.github/source.zip`. Сборка идёт через GitHub Actions:

```bash
git clone https://github.com/<you>/madcards.git
cd madcards
# Actions → Build MadCards APK → Run workflow
```

Локально (нужны JDK 17, Android SDK 35 и Gradle 8.7):

```bash
unzip .github/source.zip -d src && cd src
gradle :app:assembleDebug
```

---

## 🧪 Первый запуск

1. Введите имя (от 2 символов).
2. Выберите аватар на вкладке **Аватар**.
3. Откройте вкладку **Pass** и включите **StreetPass**. Приложение запросит Bluetooth и геолокацию.
4. Попросите знакомого с MadCards включить StreetPass рядом. Через несколько секунд встреча появится в списке.

## 🛠️ Технологии

| Слой | Что используется |
|---|---|
| UI | Kotlin, Jetpack Compose, Material 3 |
| Bluetooth | `BluetoothLeAdvertiser`, `BluetoothLeScanner`, GATT-сервер и клиент |
| Фон | Foreground Service (`connectedDevice` + `location`) с уведомлением |
| Данные | Room (история встреч), DataStore (профиль и настройки) |
| Место | `LocationManager`, `Geocoder` |
| Сборка | Gradle 8.7, AGP 8.5.2, Kotlin 1.9.24, KSP, CI через GitHub Actions |

## 🔐 Приватность

- Данные **не покидают телефон**. Сервера нет, аналитики нет, аккаунтов нет.
- По Bluetooth передаётся только **карточка**: случайный ID, имя (до 24 символов) и параметры аватара.
- Место записывается **только у вас**, и только в момент встречи. Точные координаты хранятся на телефоне в базе приложения.
- Очистить историю или удалить профиль со всеми данными можно в разделе **Ещё**.

## ⚠️ Ограничения

MadCards — **пилотная версия (v0.5)**. Честно о том, что может не работать:

- 📴 **Работает, пока включён StreetPass.** Фоновая служба показывает уведомление, и её может остановить система, особенно на телефонах с агрессивной экономией батареи (Huawei/HarmonyOS, Xiaomi, Samsung). Поможет исключение приложения из оптимизации батареи и «защищённые приложения».
- 🔁 **После перезагрузки** откройте приложение: служба не поднимается сама.
- 📡 **Не все телефоны умеют рассылать BLE.** Такие устройства смогут находить других, но сами не будут видны.
- 🧭 **Место может быть неточным** или отсутствовать, если GPS выключен или телефон в помещении.
- 🍎 **iOS пока не поддерживается.**
- 📷 **QR-обмен и Wi-Fi** пока не реализованы. Раньше были заглушки, теперь их нет.
- 🐛 **Отчёты о сбоях** сохраняются на телефоне в разделе **Pass** и помогают нам разбираться в проблемах.
